# 🔤 Real-Time OCR Text Reader

A Computer Vision application built with OpenCV and EasyOCR to detect and extract text/numbers from a webcam feed in real-time.

---

## 🚀 Features
- Real-time text bounding box detection.
- Optical Character Recognition (OCR) using Deep Learning.
- Probability threshold filtering to reduce false positives.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** OpenCV, EasyOCR, PyTorch (backend)
